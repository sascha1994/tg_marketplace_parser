# Обновление через Dockhand

GitHub Actions проверяет изменения и публикует Docker-образ в GHCR, но не подключается к серверу и не запускает деплой. Серверный стек Dockhand должен использовать `docker-compose.yml` из репозитория и загружать уже собранный образ, а не собирать его.

В настройках стека задайте переменные из `.env` приложения и `PARSER_IMAGE_TAG` (`latest` для `main` или номер релиза, например `1.4.0`). Убедитесь, что пакет `ghcr.io/sascha1994/tg_marketplace_parser` публичный; для приватного пакета настройте на сервере доступ к GHCR с правом `read:packages`. Каталог, смонтированный в `/app/data`, должен оставаться постоянным между обновлениями; при переносе существующего сервера задайте `PARSER_DATA_DIR` на прежний каталог данных.

После успешной публикации образа выполните в Dockhand для стека загрузку (pull) нового образа и redeploy. Для `latest` это действие нужно повторять после публикации каждого нужного обновления. Для выпуска или отката сначала измените `PARSER_IMAGE_TAG` на версию, опубликованную в GHCR, затем выполните pull и redeploy. Не включайте сборку образа на сервере.
