При запуске парсер пишет в журнал результат чтения файла кэша cookies. Для корректного файла выводится число записей, для повреждённого — тип ошибки или сообщение о структуре. Значения cookies в сообщения журнала не включаются.

В Telegram-панели уточнено назначение счётчика cookies для HTTP-клиентов. Схема SQLite совместима с 1.0.13.
