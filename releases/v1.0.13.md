При сбросе cookies парсер перемещает последний отклонённый кэш в
`ozon_cookies.json.rejected`. Повторный сброс при отсутствии нового кэша
сохраняет эту копию. Изменение касается сохранности файла. Ответ HTTP 403
по-прежнему означает, что витрина ограничила доступ.

Схема SQLite совместима с 1.0.12. Для отката можно выбрать образ 1.0.12
с текущим каталогом данных.
