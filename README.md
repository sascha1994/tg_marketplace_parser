# Telegram Marketplace Parser

Парсер скидок **Ozon** и **Wildberries** из папки Telegram с фильтрацией, публикацией в основной/тестовый канал и темы форум-группы, контролем актуальности в течение 24 часов и админ-панелью в Telegram.

## Возможности

- **Источники и парсинг**: сбор карточек Ozon и Wildberries из выбранной папки Telegram, извлечение цен, скидок, рейтингов, отзывов и категорий (`breadcrumbs` / `entity`).
- **Публикация в канал и темы форума**: автоматическое распределение товаров по 12 постоянным рубрикам (+ сезонная тема «Новый год и Рождество» до 14.01.2027).
- **Контроль актуальности (24 часа)**: синхронная проверка постов в основном канале и темах группы на наличие и рост цены — выгодные предложения (скидка выше порога) помечаются `❌ Неактуально` с зачёркиванием ссылки, остальные удаляются.
- **Админ-панель и статистика**: управление фильтрами, каналами и публикацией в группу через бота; раздел **📊 Статистика** разбит на 5 подразделов (**Сводка**, **Просмотры**, **Группа**, **Удаления**, **Отсев**) с адаптивным замером просмотров и фиксацией финального среза перед удалением поста.

## Ветки и Docker-образы (GHCR)

Репозиторий использует две ветки:

- **`releases`** *(основная)* — готовые релизы. При каждом обновлении ветки (или теге `vX.Y.Z`) GitHub Actions прогоняет тесты, публикует образы **`:stable`**, **`:latest`**, **`:X.Y.Z`**, `:sha-<commit>` и создаёт GitHub Release.
- **`dev`** — версии в разработке. При каждом `push` прогоняются тесты и публикуются образы **`:dev`** и `:dev-sha-<commit>`.

## Настройка

Рядом с `docker-compose.yml` создайте файл `.env`:

```dotenv
PARSER_IMAGE_TAG=stable
TG_API_ID=
TG_API_HASH=
BOT_TOKEN=
ADMIN_ID=
TG_FOLDER_NAME=Скидки
TG_TARGET_CHANNEL=
TG_TEST_CHANNEL=
TG_TEST_FORUM_ID=
```

- `TG_API_ID` и `TG_API_HASH` — ключи пользовательской сессии Telegram (Telethon).
- `BOT_TOKEN` и `ADMIN_ID` — токен бота управления и числовой ID администратора.
- `TG_FOLDER_NAME` — имя папки Telegram с каналами-источниками.
- `TG_TARGET_CHANNEL` / `TG_TEST_CHANNEL` — основной и тестовый каналы публикации.
- `TG_TEST_FORUM_ID` — полный числовой ID форум-группы с префиксом `-100` (аккаунту нужны права на публикацию в каналах и темах).
- Храните `.env` и каталог `data` вне Git. В `data` находятся сессия Telegram и база SQLite; каталог должен быть доступен на запись пользователю контейнера с UID `1000`. Путь можно переопределить через `PARSER_DATA_DIR`.

## Запуск и обновление (Dockhand / Docker Compose)

При первом запуске без сохранённой сессии авторизуйте аккаунт в интерактивном терминале:

```bash
docker compose run --rm tg_deals_parser
```

После авторизации остановите процесс (`Ctrl+C`) и запустите сервис в фоне:

```bash
docker compose up -d
docker compose ps
docker compose logs --tail=100
```

### Обновление через Dockhand

Подробная инструкция находится в [DOCKHAND_DEPLOYMENT.md](DOCKHAND_DEPLOYMENT.md):

- **Релизы (прод)**: используйте `docker-compose.yml` и `PARSER_IMAGE_TAG=stable` (значение по умолчанию). После выхода релиза в `releases` кнопка **Check for Updates / Update** (или автообновление по расписанию) сразу находит новый digest и обновляет контейнер.
- **Тестовая версия (`dev`)**: переключите `PARSER_IMAGE_TAG=dev` в текущем стеке и выполните **Redeploy**, либо поднимите отдельный тестовый стек по `docker-compose.dev.yml`.
- **Откат**: укажите конкретную версию (например, `PARSER_IMAGE_TAG=1.1.5`) и выполните **Redeploy**.

## Темы форум-группы

В боте управления отправьте `/start` → **Сервис** → **«Включить / выключить публикацию в группу»**. Если рубрика товара не определена, карточка публикуется только в выбранный канал.

Поддерживаемые названия тем:

- Детская одежда и обувь
- Игрушки и товары для детей
- Дом и кухня
- Одежда и обувь для взрослых
- Техника и электроника
- Красота и уход
- Продукты и напитки
- Бытовая химия
- Зоотовары
- Автотовары
- Спорт и туризм
- Ремонт и инструменты

Ручной инструмент и крепёж направляются в «Ремонт и инструменты», электроинструмент — в «Техника и электроника».
